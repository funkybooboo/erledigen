# USE-22: Words and controls that agree

As an app user, I want natural language and manual controls blended
into one surface, so that typing a schedule and clicking one can never
disagree.

**Status**: planned
**Version**: v0.17.0

## Acceptance criteria
- [ ] Type NL; the manual controls auto-populate and stay editable
- [ ] Touching any control rewrites the text to the canonical phrase
- [ ] The live hint always shows the understood schedule
