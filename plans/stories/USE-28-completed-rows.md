# USE-28: Done means struck through

As an app user, I want a completed task to show its full title struck
through with no checkbox at all, so that the strike IS the completed
state -- like crossing off a paper list.

**Status**: planned
**Version**: v0.18.0

## Acceptance criteria
- [ ] A done task's row: full title crossed out, no checkbox
- [ ] Un-completing stays reachable (Space + row actions); the build
      decides the click affordance
