# USE-8: The privacy commitment, stated plainly

As an app user, I want the no-tracking commitment stated in the user
docs, so that I know what the app knows about me: nothing beyond what
I store in my own database.

**Status**: done
**Version**: v0.11.0

## Acceptance criteria
- [x] docs/use/ states the promise (ADR-019) without hedging
- [x] No analytics, no telemetry, no tracking -- any deployment mode

## Notes

ADR-019. Privacy is the product's stance, not a self-hosting side
effect.
