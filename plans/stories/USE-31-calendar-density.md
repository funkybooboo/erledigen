# USE-31: A calendar with a view

As an app user, I want the Calendar modal to show per-day task density
across the month, so that it gives a high-level view of what is coming
instead of only navigating.

**Status**: planned
**Version**: v0.18.0

## Acceptance criteria
- [ ] Month grid shows per-day task/appointment density
- [ ] Navigation behavior stays (pick a date -> scroll + center the
      day list; Today resets the view)

## Notes

UX-audit finding: the calendar was "kinda pointless" next to the month
minimap. Time-awareness without an hour grid (ADR-014).
