# USE-29: Drag the task, not a grip

As an app user, I want the task row itself to be draggable (click to
edit, drag to move, no visible handle), so that moving work feels
like moving paper, not operating a machine.

**Status**: planned
**Version**: v0.18.0

## Acceptance criteria
- [ ] The row initiates the drag; text stays selectable
- [ ] No visible grip handle

## Notes

UX-audit finding. Today only the hover grip drags.
