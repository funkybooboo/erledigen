# USE-4: Tags carry colors

As an app user, I want tags to have distinct colors, so that my
filters and rows are scannable at a glance.

**Status**: planned
**Version**: v0.11.0

## Acceptance criteria
- [ ] Tags auto-assign distinct pastel colors on creation
- [ ] User can override the color for any tag
- [ ] Tag chips in task rows and the filter bar reflect the color

## Notes

Tag colors ride UserPreferences (ADR-008 snapshot coverage as it
grows).
