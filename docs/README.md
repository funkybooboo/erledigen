# Erledigen Documentation

The docs are organized by role (ADR-020) -- pick the one that is you:

- **[Use](./use/)** -- for app users: what Erledigen is, how to work in
  it, notes, import/export. Non-technical.
- **[Host](./host/)** -- for operators: install and run an instance,
  configure it, upgrade it, back it up, monitor it.
- **[Build](./build/)** -- for developers: architecture, standards,
  process, and the ADRs. Start at the
  [build docs index](./build/README.md).
